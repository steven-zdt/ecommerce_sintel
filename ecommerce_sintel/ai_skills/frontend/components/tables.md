# Tables

Este proyecto tiene **un unico patron de tabla** (HTML nativo + Bootstrap), documentado en
[datatable.md](datatable.md). No existe una libreria/componente de tabla diferente — este archivo
existe solo para que el nombre de dominio propuesto (`components/tables.md`) no quede sin
resolver. No dupliques contenido aqui: si necesitas extender el patron de tabla, hazlo en
`datatable.md`.
