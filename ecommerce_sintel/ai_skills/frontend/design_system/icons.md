# Icons — Bootstrap Icons

Todos los iconos usan el prefijo `bi bi-*` (Bootstrap Icons 1.11.3, via CDN). No importar
librerias de iconos adicionales.

| Contexto | Icono |
|---|---|
| Nueva accion | `bi-plus-lg` |
| Editar | `bi-pencil` (con `text-primary`) |
| Eliminar / trash | `bi-trash` (con `text-danger`) |
| Confirmar/check | `bi-check` |
| Cancelar/cerrar | `bi-x` |
| Advertencia | `bi-exclamation-triangle-fill` |
| Informacion | `bi-info-circle` |
| Dashboard | `bi-speedometer2` |
| Perfil/usuario | `bi-person-circle` |
| Usuarios | `bi-people` |
| Producto/caja | `bi-box-seam` |
| Categoria | `bi-tag` |
| Marca | `bi-bookmark-star` |
| Impuesto | `bi-percent` |
| Inventario | `bi-stack` |
| Orden | `bi-bag-check` |
| Cotizacion | `bi-file-earmark-text` |
| Servicios | `bi-tools` |
| Llave/ajuste | `bi-wrench-adjustable` |
| Niveles | `bi-bar-chart-steps` |
| Diagrama/categoria servicio | `bi-diagram-3` |
| Renta/camion | `bi-truck` |
| Categoria renta | `bi-tags` |
| Mano de obra | `bi-person-gear` |
| Marketing | `bi-graph-up-arrow` |
| Campanas | `bi-megaphone` |
| Tienda | `bi-shop` |
| Operaciones | `bi-clipboard-data` |
| SEO/buscar | `bi-search` |
| General/carpeta | `bi-folder` |
| Capas/variantes | `bi-layers` |
| Porcentaje descuento | `bi-percent` |
| Reloj/promo activa | `bi-clock` |

**Regla:** antes de usar un icono nuevo, verificar que existe en Bootstrap Icons 1.11.3. No
inventar nombres de clase `bi-*`.
